# 護理新人臨床急症情境手冊｜互動版

這個資料夾可直接部署至 GitHub Pages。網站是單檔離線設計，不使用外部套件或遠端資源。

## GitHub Pages 發布方式

1. 建立一個新的 GitHub repository。
2. 將本資料夾內的 `index.html`、`.nojekyll` 和 `README.md` 上傳至 repository 根目錄。
3. 開啟 repository 的 **Settings → Pages**。
4. 在 **Build and deployment** 選擇 **Deploy from a branch**。
5. Branch 選擇 `main`，資料夾選擇 `/(root)`，然後按 **Save**。
6. 等待 GitHub Pages 顯示網站網址。

## 保留的互動功能

- 按鈕、鍵盤方向鍵及手機滑動翻頁
- 顯示或隱藏 ISBAR 示範與評核指標
- 每章作答筆記與重新練習
- 自動保存閱讀進度與筆記

閱讀進度和筆記使用瀏覽器本機儲存，不會上傳至 GitHub，也不會讓教師看到其他人的作答。
