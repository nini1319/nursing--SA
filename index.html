自學教材使用方法

這份教材不是只用來閱讀答案，而是讓你在安全、沒有時間壓力的情境中，先練習「察覺異常、做出判斷、採取處置、清楚通報」。

為什麼要自己練習？

  • 建立臨床警覺：反覆辨認早期警訊，減少只看到單一數值或表面行為。
  • 練習思考順序：先評估、再處置、持續重評，逐漸形成穩定流程。
  • 練習說出口：把判斷整理成ISBAR，可及早、具體地向團隊求援。
  • 看見自己的落差：先作答與自評，再比較參考答案，才知道下一次要改進什麼。
  • 允許安全地重來：自學時可以暫停、重做與修正，不必等到真實緊急事件才第一次練習。

建議學習流程

  1. 填寫所屬單位與員工編號。
  2. 每次選擇一個臨床情境，不必一次完成全部章節。
  3. 先閱讀題幹與情境進展，不要立刻展開參考答案。
  4. 在作答區寫下異常判斷、處置順序與ISBAR草稿。
  5. 依當次表現完成1–4分自評。
  6. 再展開ISBAR示範與正式評核指標，逐項比較差異。
  7. 按「重新練習」，針對不足項目再做一次。

重要提醒：本教材用於新人自學與模擬訓練，不能取代實際病人評估、醫囑、院內緊急流程或最新版臨床指引。真實臨床狀況應立即依單位SOP求援與處置。

01急性呼吸喘

Acute Dyspnea

背景與常見盲點｜呼吸型態改變導致氧合不足。常見於心衰竭、肺栓塞、氣胸、肺炎、COPD 惡化、焦慮。護理新人常見盲點：只看 SpO2 而忽略呼吸型態與說話能力。

學習目標

  1. 辨識呼吸喘的早期症狀與危險體徵
  2. 正確測量呼吸頻率、聽診呼吸音並判讀
  3. 執行初步處置（擺位、給氧、監測）
  4. 在 5 分鐘內以 ISBAR 完成通報

學習重點（K 知識／A 態度／S 技能）

  • K說出呼吸喘常見的心因性與肺因性原因至少各 2 項
  • K說出呼吸窘迫的危險體徵（RR>30、三凹症、鼻翼搧動、講話斷句、發紺、SpO2<90%）
  • A能同理病人恐懼並以穩定語調安撫，操作前告知目的
  • S正確測量呼吸頻率滿 1 分鐘（不可估算）、聽診六個肺野
  • S正確擺位（半坐臥/端坐）、依醫囑給氧並重新評估
情境故事｜王先生，67歲，肺癌住院化療第5天。14:30 按呼叫鈴主訴「護理師，我喘得快沒辦法呼吸了」。護理新人進入病房發現病人端坐床上、身體前傾、臉部潮紅、頸靜脈怒張、講話無法成句。

情境題幹 · 一開始所知訊息

目前治療化療第2療程，右鎖骨下 Port-A

理學檢查三凹症(+)、鼻翼搧動(+)、右下肺呼吸音減弱

角色需求

  • 病人：端坐、講話斷句、表情驚恐，只能回答單字
  • 護理新人：主護，需完成評估與通報
  • 臨床教師：觀察並於 Debriefing 回饋
  • 醫師：接獲通報後到達，開立醫囑

情境進展

第一幕 (0-3分)病人主訴喘。新人應：觀察呼吸型態→測 SpO2 與 RR→搖高床頭→給氧
第二幕 (3-8分)SpO2 降至 82%，出現意識混亂、躁動。新人應：提高氧氣濃度、通知醫師、準備急救設備
關鍵事件

SpO2 降至 82%，病人開始躁動、答非所問 → 需辨識為缺氧引起的意識變化，而非情緒問題。

02缺氧

Hypoxemia

背景與常見盲點｜動脈血氧不足 (SpO2<90% 或 PaO2<60 mmHg)。護理新人常見盲點：把缺氧引起的躁動誤判為情緒問題或譫妄而給予約束。

學習目標

  1. 辨識缺氧的中樞神經表現
  2. 正確判讀 SpO2 並排除測量誤差
  3. 執行氧氣治療並評估成效
  4. 以 ISBAR 通報氧合惡化

學習重點（K 知識／A 態度／S 技能）

  • K說明缺氧對腦部與心肌的影響
  • K辨識缺氧的早期(躁動、不安、心搏過速)與晚期(發紺、心搏過緩、意識喪失)表現
  • K說出 SpO2 測量誤差來源（末梢冰冷、指甲油、低灌流、一氧化碳中毒）
  • S正確安置血氧探頭並確認波形
  • S給氧後 5-10 分鐘重新評估並記錄
情境故事｜陳女士，55歲，肺炎住院第3天。護理新人執行晨間護理時，發現病人昨晚狀況尚可，今晨面色晦暗、口唇泛紫，雖有接氧氣但躁動不安、一直要拔管路。

情境題幹 · 一開始所知訊息

目前治療Nasal cannula 2L/分、抗生素治療中
生命徵象HR 102 bpm、BP 140/90 mmHg、RR 28/分、SpO2 85% (O2 2L/分)、T 37.8°C
理學檢查口唇發紺、末梢冰冷、意識躁動、雙下肺囉音
醫療診斷Hypoxemia secondary to pneumonia

角色需求

  • 病人：躁動、拉扯氧氣管、答非所問
  • 護理新人：需辨識躁動來自缺氧而非譫妄
  • 臨床教師：引導鑑別診斷思考
  • 醫師：評估是否需升階氧療

情境進展

第一幕發現病人躁動、發紺。新人應：先確認 SpO2 與探頭位置，而非先約束病人
第二幕氧氣管脫落，SpO2 降至 78%。新人應：立即重接、提高氧流量、通報
關鍵事件

病人躁動導致氧氣管脫落，SpO2 降至 78% → 關鍵在於辨識「躁動是缺氧的結果，不是原因」，禁止優先給予約束或鎮靜。

03住院中突發梗塞性中風

In-hospital Ischemic Stroke

背景與常見盲點｜病人原本清醒、因檢查住院，後來突然變得安靜淡漠。若只把行為改變解讀為疲倦、情緒低落或不合作，可能漏掉顏面歪斜、構音改變與單側無力等急性中風警訊。Time is Brain：應立刻確認最後正常時間並啟動院內中風流程。

學習目標

  1. 察覺「突然變得淡漠」可能是急性神經學變化，而非單純情緒問題
  2. 以 FAST 快速確認顏面、手臂與語言異常
  3. 精確確認並記錄最後正常時間（Last Known Well）與症狀被發現時間
  4. 完成血糖與初步神經學評估，立即啟動院內中風流程
  5. 以 ISBAR 清楚通報病人與基準狀態的差異

學習重點（K 知識／A 態度／S 技能）

  • K說出 FAST：Face 顏面歪斜、Arm 單側手臂無力、Speech 語言或構音異常、Time 立即處理
  • K說明最後正常時間會影響急性再灌流治療評估，不能只記錄「發現異常」的時間
  • S比較病人目前狀態與原本清醒、可正常活動及對答的基準狀態
  • S正確評估意識、瞳孔、顏面對稱、語言與四肢肌力，並立即測血糖
  • A不以「淡漠、心情不好、不配合」過早定論，主動尋找可逆或危急原因
情境故事｜陳先生，66 歲，因近期反覆頭暈住院安排檢查。入院至今意識清楚，能自行下床、正常交談。今天 08:00 早餐時護理師仍看見他可正常說話並自行使用餐具；08:30 巡房時，他比平常安靜、表情淡漠，只簡短回應。工作人員起初以為他只是沒睡好或心情不佳。08:45 再次接觸時，才發現他嘴角歪斜、說話含糊，右手抬不起來，右腳也不太會動。

角色需求

  • 病人：一開始僅顯得安靜、淡漠、回答簡短；進一步評估時呈現構音含糊與右側無力
  • 護理新人：需從「與原本不一樣」察覺異常，避免停留在情緒或疲倦的解釋
  • 同班護理師：可提供 08:00 病人仍正常的目擊資訊
  • 臨床教師：觀察新人是否主動執行 FAST、血糖與神經學評估
  • 醫師／中風小組：評估影像與急性再灌流治療適應性

情境進展

第一幕 (0–3分)病人比平常安靜、表情淡漠，只簡短回答。新人應：先比較基準狀態，檢查意識、語言、顏面與雙側肢體，而不是直接判定為疲倦或情緒低落。
第二幕 (3–8分)請病人微笑、抬高手臂與說完整句子時，發現右側嘴角下垂、右臂下墜、構音含糊。新人應：立即完成 FAST、測血糖、確認最後正常時間並啟動院內中風通報。
第三幕 (8–12分)等待中風小組期間，右腿無力加劇、回答更慢。新人應：重新量化神經學狀態、維持安全、依院內流程準備緊急影像與檢驗，立即回報惡化。
關鍵事件

「突然淡漠」是本案最早的行為改變；一旦病人和原本清醒、可正常交談活動的狀態不同，就應立即進行神經學評估。發現顏面歪斜、單側無力或語言異常時，不可等待症狀自行恢復。

04輸血過敏反應

Transfusion Reaction

背景與常見盲點｜輸血後 15 分鐘內最易發生反應。護理新人常見盲點：僅停止滴速但未更換輸液套組、或未保留血袋送檢。

學習目標

  1. 辨識輸血反應的類型與症狀
  2. 立即執行停止輸血的標準流程
  3. 保留檢體與血袋依規定送檢
  4. 以 ISBAR 通報並完成不良事件紀錄

學習重點（K 知識／A 態度／S 技能）

  • K區分過敏反應、急性溶血反應、發熱性非溶血反應、細菌污染之症狀差異
  • K說出輸血前後的核對與監測時間點（前15分鐘須床邊守候）
  • S正確執行五步驟：停止輸血→更換輸液套組並以生理食鹽水維持靜脈路→評估生命徵象→通知醫師與血庫→保留血袋及輸血套組送檢
  • S正確採集反應後血液及尿液檢體
  • A安撫病人焦慮並清楚說明處置理由

05呼吸道阻塞

Airway Obstruction

背景與常見盲點｜氣道被異物、分泌物或水腫阻塞。關鍵判斷點在於「部分阻塞」與「完全阻塞」的區分，兩者處置完全不同。

學習目標

  1. 區分部分與完全呼吸道阻塞
  2. 執行對應年齡的異物哈姆立克法
  3. 維持氣道通暢並持續監測
  4. 緊急通報並準備氣道處置設備

學習重點（K 知識／A 態度／S 技能）

  • K說明部分阻塞（可咳嗽、有聲音、有喘鳴）與完全阻塞（無聲、無法咳嗽、雙手抓喉）之區別
  • K說出部分阻塞時應「鼓勵咳嗽、勿盲目挖取」的理由
  • S正確執行成人／兒童／嬰兒的異物哽塞處理法
  • S辨識喘鳴音 (stridor) 並與哮鳴音 (wheezing) 區別
  • A安撫哭鬧幼童與驚慌家屬，避免病人躁動加重阻塞
情境故事｜黃小弟，4歲，於家中吃花生後突然劇烈咳嗽，家屬送至急診。護理新人接觸病人時，聽到高調吸氣性喘鳴音，小孩劇烈咳嗽、驚恐哭鬧，但仍能發出聲音。

情境題幹 · 一開始所知訊息

理學檢查吸氣性喘鳴音 (stridor)、輕微肋間凹陷、能咳嗽並發出聲音、無發紺
目前判斷部分呼吸道阻塞（氣道尚未完全阻塞）
醫療診斷疑似異物吸入 (Foreign Body Aspiration)

  • 病人（4歲）：哭鬧掙扎、劇烈咳嗽，仍能發出聲音
  • 家屬：驚慌自責、要求「趕快把東西挖出來」
  • 護理新人：需正確判斷阻塞程度並避免不當介入
  • 臨床教師：糾正盲目挖取的危險行為

第一幕部分阻塞。新人應：鼓勵咳嗽、給氧、持續監測、勿盲目挖取、勿讓病人平躺、通報

06低血糖

Hypoglycemia

背景與常見盲點｜血糖 <70 mg/dL。護理新人常見盲點：意識改變病人第一時間未測血糖；或給予無法快速吸收的食物（如巧克力、含脂點心）。

學習目標

  1. 辨識低血糖的自主神經與中樞神經症狀
  2. 於任何意識改變時優先測量血糖
  3. 正確執行 15-15 原則
  4. 以 ISBAR 通報並找出誘因

學習重點（K 知識／A 態度／S 技能）

  • K說出低血糖的自主神經症狀（發抖、冒冷汗、心悸、飢餓）與中樞神經症狀（意識混亂、抽搐、昏迷）
  • K說明 15-15 原則：給予 15 克可快速吸收醣類，15 分鐘後複測
  • K說出意識不清病人禁止由口進食，應給 IV 50% Glucose 或 Glucagon
  • S正確執行指尖血糖檢測（含消毒、去除第一滴血）
  • S能追溯誘因（漏餐、胰島素劑量、運動量、腎功能）
情境故事｜張女士，58歲，糖尿病病人。今晨忘記進食即自行施打胰島素。10:00 家屬按鈴表示「我媽媽剛剛一直冒冷汗，講話有點怪怪的」。護理新人到床邊發現病人臉色蒼白、全身冒冷汗、手部微顫。

  • 病人：意識清楚但反應變慢，可吞嚥
  • 家屬：焦急詢問「是不是中風了？」
  • 護理新人：需優先測血糖並正確給糖
  • 臨床教師：強調「任何意識改變先測血糖」原則

07腹腔手術術後出血

背景與常見盲點｜術後內出血初期血壓可能因代償而正常，護理新人常見盲點：只看血壓正常就放心，忽略心搏過速、脈壓變窄與尿量減少等早期代償徵象。

學習目標

  1. 辨識術後出血的早期代償徵象
  2. 執行系統性腹部評估與引流管監測
  3. 辨識低血容積休克並執行初步處置
  4. 以 ISBAR 通報並準備輸血與再手術

學習重點（K 知識／A 態度／S 技能）

  • K說明失血代償機轉與休克分期（Class I-IV）
  • K辨識早期徵象：HR↑、脈壓變窄、尿量<0.5 mL/kg/hr、焦躁不安、皮膚濕冷
  • S執行腹部視診、聽診、觸診（腹圍測量、腹脹、壓痛、反彈痛）
  • S正確監測引流管性狀與量、傷口敷料滲濕程度
  • S建立兩條大管徑靜脈路（18G 以上）並準備備血

背景與常見盲點｜突發規則性窄 QRS 波心搏過速 (通常 150-250 bpm)。關鍵判斷點：病人是否血流動力學穩定，決定藥物或電擊治療。

  2. 判斷血流動力學是否穩定
  3. 協助執行迷走神經刺激法
  4. 備妥藥物與電擊器並以 ISBAR 通報

09呼吸性酸中毒

Respiratory Acidosis

背景與常見盲點｜CO2 滯留導致 pH<7.35、PaCO2>45 mmHg。護理新人常見盲點：只看 SpO2，忽略「SpO2 正常但通氣不足」的情況，特別是使用鎮靜劑或麻醉性止痛藥後。

學習目標

  1. 辨識通氣不足的臨床表現
  2. 正確判讀動脈血液氣體分析
  3. 辨識藥物引起的呼吸抑制
  4. 以 ISBAR 通報並準備通氣支持

學習重點（K 知識／A 態度／S 技能）

  • K說明 CO2 滯留的病理生理與對意識的影響（CO2 麻醉）
  • K判讀 ABG：pH、PaCO2、HCO3 的關係與代償判斷
  • K說出常見誘因：鴉片類藥物、鎮靜劑、COPD 惡化、神經肌肉疾病
  • S評估呼吸「深度」而非僅頻率，辨識淺快或慢而淺的無效通氣
  • S說出 COPD 病人的給氧目標 (SpO2 88-92%) 與高濃度氧的風險

Altered Level of Consciousness

背景與常見盲點｜意識改變是多種急症的共同表現。護理新人常見盲點：只記錄「病人比較嗜睡」而未量化 GCS，導致無法呈現趨勢變化。

學習目標

  1. 正確評估並量化 GCS
  2. 以系統性方式鑑別意識改變的可逆原因
  3. 完成瞳孔與肢體神經學評估
  4. 以 ISBAR 呈現趨勢變化並通報

學習重點（K 知識／A 態度／S 技能）

  • K說出意識改變的可逆原因（低血糖、缺氧、藥物、電解質異常、感染、腦部病變）
  • K正確評分 GCS 三面向 (E4 V5 M6) 並說明各分數定義
  • S正確執行瞳孔大小與對光反射檢查、四肢肌力與對稱性評估
  • S熟悉 AVPU 快速分級（Alert／Verbal／Pain／Unresponsive）
  • S能以前後 GCS 比較呈現趨勢，而非僅描述「比較睏」

11敗血性休克

Septic Shock

背景與常見盲點｜感染引起的失控性全身反應併循環衰竭。強調 Sepsis Bundle 於 1 小時內完成。護理新人常見盲點：先給抗生素才抽血培養，導致培養結果失真。

學習目標

  1. 以 qSOFA 早期辨識敗血症
  2. 正確執行 Sepsis Bundle 的護理項目
  3. 理解血液培養須於抗生素前採檢
  4. 以 ISBAR 通報並啟動敗血症流程

學習重點（K 知識／A 態度／S 技能）

  • K說明敗血症的病理生理（血管擴張、微血管滲漏、組織灌流不足）
  • K說出 qSOFA 三項：意識改變、收縮壓 ≤100 mmHg、呼吸速率 ≥22/分
  • K說出 1 小時 Sepsis Bundle：測乳酸、抽血液培養（抗生素前）、給廣效抗生素、輸液復甦 30 mL/kg、必要時升壓劑
  • S正確採集雙套血液培養（不同部位、足量、無菌技術）
  • S建立大管徑靜脈路並執行快速輸液，同時監測輸液反應

12突發心跳停止

Sudden Cardiac Arrest

背景與常見盲點｜心臟失去有效輸出。存活關鍵在生存之鏈：早期辨識求救、早期 CPR、早期去顫、高品質高級救命術。護理新人常見盲點：花太多時間確認脈搏而延誤按壓。

學習目標

  1. 於 10 秒內完成無反應與無脈搏判斷
  2. 立即啟動急救小組並開始高品質 CPR
  3. 正確使用 AED／去顫器
  4. 於團隊中執行明確角色與閉環式溝通

學習重點（K 知識／A 態度／S 技能）

  • K說明生存之鏈與早期去顫對存活率的影響
  • K區分可電擊心律（VF／無脈搏 VT）與不可電擊心律（Asystole／PEA）之處置差異
  • S高品質 CPR 五要素：速率 100-120/分、深度 5-6 cm、完全回彈、減少中斷、避免過度換氣
  • S正確操作 AED／去顫器並確保電擊前人員淨空
  • S使用閉環式溝通 (Closed-loop communication) 回覆醫囑並記錄時間
情境故事｜王先生，55歲，冠狀動脈疾病病史，於病房走廊突然倒地。護理新人第一時間到達，發現病人無反應、無正常呼吸。

情境題幹 · 一開始所知訊息

過去病史冠狀動脈心臟病、陳舊性心肌梗塞、高血壓
發現情境病房走廊目擊倒地，倒地時間 10:42
初步評估無反應、無正常呼吸（僅有瀕死喘息 gasping）、10 秒內未觸及頸動脈搏動

醫療診斷心因性院內心跳停止 (In-hospital Cardiac Arrest)

角色需求

  • 病人：無反應、無脈搏、瀕死喘息
  • 第一發現者（護理新人）：確認無反應→大聲求救→立即開始胸部按壓
  • 第二位護理師：推急救車與去顫器、建立靜脈路
  • 第三位護理師：記錄時間、藥物與電擊次數
  • 臨床教師：監控按壓品質、確保每 2 分鐘輪替
  • 醫師：擔任急救指揮 (Team Leader)、判讀心律、下達醫囑

第一幕 (0-2分)發現倒地。新人應：拍肩呼喚→大聲求救並請人拿 AED→10 秒內確認脈搏→立即開始胸部按壓

關鍵事件
